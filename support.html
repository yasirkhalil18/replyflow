Help Center & Knowledge Base

Find step-by-step setup guides, plugin documentation, and quick answers to common questions.

🎟️ How to setup the Support Ticket Desk plugin? ▼

1. Open the ReplyFlow Web Dashboard and select your server from the top dropdown.

2. Navigate to Support Ticket Desk in the left sidebar.

3. Customize your Ticket Embed Title, allowed staff roles, and daily ticket limits.

4. Click Save Ticket Setup. The bot will automatically create `#tickets` with the permanent interactive support button embed.

📊 How do Live Server Stats voice counters update? ▼

ReplyFlow features a real-time 3-second database sync loop. When you toggle ON/OFF any of the 6 voice counters (Total Members, Online Members, Boosts, Admins, Bots, Moderators) on the web dashboard, the bot automatically renames or deletes/restores the corresponding voice channels in Discord instantly.

🤖 How does the AI Assistant RAG Knowledge Base work? ▼

The AI Smart Assistant is powered by Google Gemini 1.5 Pro AI with RAG (Retrieval-Augmented Generation) memory. You can enter your server's rules, FAQs, and custom details into the Web Dashboard RAG Knowledge Base box. The bot will answer member questions 24/7 in `#ai-assistant` or when pinged.

📜 How does the Permanent Deleted Message Archiver work? ▼

The Audit & Security Shield intercepts deleted messages in real time. Even if a user sends and deletes a message immediately, ReplyFlow archives the text content, author username, channel name, attachments, and timestamp permanently to SQLite database and sends a report to `#audit-logs`.

🏆 How to check XP Rank Cards and Leaderboards? ▼

Members automatically earn XP by sending chat messages. Anyone can type /rank in any channel to display their custom canvas rank card, or visit #leaderboard-and-ranks to view top server ranks.
