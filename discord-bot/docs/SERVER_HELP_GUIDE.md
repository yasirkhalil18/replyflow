# 📖 NIT- NOIR INSIGHT TRADER - Official Member Help Guide

Welcome to **NIT- NOIR INSIGHT TRADER**! This guide will help you navigate the server, use automated tools, and get support.

---

### 🚀 Quick Start Guide

#### 1. 💬 Chatting & Earning XP (Leveling System)
- Every message you send in text channels earns you **15–25 XP**.
- **Check Your Rank & Level**: Type `/rank` in chat to see your level card and total XP.

#### 2. 🤖 AI Assistant (Gemini 2.0 AI)
- Need quick answers about the server, trading signals, or rules?
- **How to use**:
  - Type `/ai <your question>`
  - Or mention `@Automation Bot <your question>` directly in any text channel.
- *Note: The AI answers server and trading questions, while filtering off-topic queries.*

#### 3. 🎟️ Support Ticket Desk (Need Staff Help?)
- Have a private question, billing issue, or trade signal query?
- **How to open a ticket**:
  - Type `/ticket` in chat or click the **`📩 Create Support Ticket`** button.
  - A private `#ticket-username` channel will be created for you and server staff.

#### 4. 💡 Community Suggestions & Voting
- Have an idea to improve the server?
- **How to suggest**:
  - Type `/suggest <your idea>` (e.g. `/suggest Add daily crypto analysis channel`).
  - Your suggestion will be posted to `#suggestions` with `👍` and `👎` reaction buttons for community voting.

#### 5. 📢 Social Media Feeds
- Stay up-to-date with our YouTube videos and Twitter/X market signals.
- **How to view feeds**: Type `/feed` in chat.

---

### 🛡️ Server Rules & Auto-Moderation

1. **Be Respectful**: Treat all community members and staff with courtesy.
2. **No Spam or Fast Flooding**: Sending messages too quickly triggers the Anti-Spam rate limiter.
3. **No External Links**: Posting external web links or Discord invite links is prohibited (Anti-Link Shield).
4. **No Credential / Token Leaks**: Never post bot tokens or secret keys in chat (Token Leak Shield automatically deletes them).
